Hermes Calendar Integration

Application home page for a private, single-user OAuth client.

What this application is

Hermes Agent is a personal desktop assistant. This OAuth client lets it read and write Google Calendar events on behalf of its sole user — the owner of the Google account that authorises it.

What it does

  • Reads calendar events, so the owner can ask what is scheduled.
  • Creates, updates, and deletes calendar events when the owner asks it to.

What it does not do

It does not access Gmail, Google Drive, Google Contacts, Google Sheets, or Google Docs. It is not offered to the public and has exactly one user.
