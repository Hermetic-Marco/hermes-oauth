Privacy Policy

Last updated: 13 October 2026.

Scope

This policy covers the private OAuth client Hermes Agent and its use of Google user data. The application has exactly one user: the owner of the Google account that authorises it. It is not available to the public.

What data is accessed

The application requests a single Google OAuth scope: https://www.googleapis.com/auth/calendar. Through that scope it can read and modify calendar events in the authorising user's Google Calendar.

It does not request or receive access to Gmail, Google Drive, Google Contacts, Google Sheets, or Google Docs.

How data is used

Calendar data is used only to answer the owner's requests and to create, update, or delete calendar events at the owner's instruction. It is not used for advertising, is not used to train machine learning models, and is not sold.

How data is stored

An OAuth refresh token is stored locally on the owner's own computer. Calendar content is retrieved on demand and is not retained by any third-party service.

Sharing

No Google user data is shared with any third party. The only external processing is the request the owner themselves makes to an AI model provider in order to use the assistant.

Retention and deletion

The stored refresh token can be revoked at any time from the owner's Google Account security settings at myaccount.google.com/permissions, which immediately ends the application's access. Deleting the local token file removes all locally stored credentials.

Contact

This application is for personal use only. Questions can be directed to its owner.
